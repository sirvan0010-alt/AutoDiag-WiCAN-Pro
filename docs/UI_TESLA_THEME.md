# UI direction — Tesla-like phone chrome

Torque / Car Scanner / Watchdog visuals are out of scope.

## Tokens

- Dark first: canvas `#0B0D10`, cards `#111318`, hairline `#2A2F38`.
- Accent red `#E82127` for primary / warnings only.
- Light mode: invert surfaces, same accent and spacing.
- Large numerals for live values; thin rings, not skeuomorphic gauges.
- Connection chip: mode / latency / effective Hz / RX.
- UNAVAILABLE is muted, never a red error.
- Experimental WRITE (Summon): amber safety strip, not everyday red.
